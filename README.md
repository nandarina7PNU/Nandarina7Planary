# Planary

> 현재 버전: **v4.0 — Planary AI**

하루의 할 일과 일정을 주간·월간 캘린더로 계획하고, 실제로 사용한 시간을 10분 단위로 기록하는 웹 플래너입니다.

만든 이유는... J가 되고 싶어서 입니다. 필요하신분 가져가서 쓰셔요 ㅎㅎㅎ

## 주요 기능

- 수집함과 이번 주 목록으로 할 일 정리
- 큰 할 일을 체크리스트로 나누고 세부 메모·진행률·마감일 관리
- 세부 항목을 모두 마치면 묶음 할 일을 자동 완료
- Gemini가 자연어를 일정·반복 일정·할 일·묶음 할 일로 자동 분류
- 주간 캘린더에서 24시간 일정 관리
- 월간 캘린더에서 일정과 마감일 확인
- 매주 반복되는 일정 등록
- 일정 분류와 색상 관리
- 24시간을 10분 단위로 하루 시간 기록
- 계획한 시간과 실제 기록 비교 및 분류별 사용 시간 요약
- 일정과 기록을 JSON 파일로 내보내고 다시 가져오기
- 브라우저에 일정과 설정 자동 저장

## 실행 방법

### 준비 사항

- Node.js 22.13.0 이상
- npm

### 로컬 개발 서버

```bash
git clone https://github.com/nandarina7PNU/Nandarina7Planary.git
cd Nandarina7Planary
npm install
```

Google AI Studio에서 발급한 키를 사용하려면 프로젝트 루트에 `.env.local` 파일을 만들고 다음 값을 넣습니다.

```bash
GEMINI_API_KEY=발급받은_API_키
```

그다음 개발 서버를 실행합니다.

```bash
npm run dev
```

실행 후 브라우저에서 [http://localhost:3000](http://localhost:3000)에 접속합니다.

### 프로덕션 빌드

```bash
npm run build
npm run start
```

### 코드 검사

```bash
npm run lint
```

## Planary AI 사용법

왼쪽 아래의 **Planary AI** 입력란에 평소 말하듯 내용을 적습니다. `Enter`를 누르면 AI가 날짜, 시간, 반복 요일과 체크리스트를 분리해 미리 보여주며, `Shift + Enter`로 줄을 바꿀 수 있습니다. 내용을 확인하고 필요 없는 항목을 제외한 뒤 등록하세요.

입력 예시:

```text
매주 월요일 수요일 오후 4시 30분부터 5시 45분까지 플랫폼 수업
9월 7일까지 조교 신청서와 재학증명서, 건강보험자격득실확인서를 준비해서 제출
내일 오후 11시부터 다음 날 오전 1시까지 프로젝트 작업
```

API 키는 서버에서만 사용되며 브라우저나 JSON 백업에 포함되지 않습니다. `.env.local` 파일도 Git에서 제외되므로 실제 키를 저장소에 올리지 마세요.

## 데이터 저장

현재 일정, 할 일, 분류, 하루 기록은 사용하는 브라우저의 `localStorage`에 저장됩니다. 브라우저 데이터 삭제 또는 다른 기기·브라우저 사용 시 기존 데이터가 자동으로 옮겨지지 않습니다.

앱 오른쪽 아래의 **분류 설정 → 내보내기**를 누르면 일정, 할 일 체크리스트, 하루 기록과 설정을 JSON 파일로 백업할 수 있습니다. **가져오기**에서 해당 파일을 선택하면 현재 데이터를 백업 내용으로 복원합니다. 이전 버전에서 내보낸 Planary 백업도 가져올 수 있습니다.

## 묶음 할 일 사용법

할 일 목록 위의 **＋ 묶음 할 일**을 누르고 큰 일의 제목과 마감일을 입력합니다. 필요한 준비물을 세부 항목으로 추가하고 각 항목에 메모를 남길 수 있습니다. 할 일 제목을 누르면 상세 내용을 다시 열 수 있으며, 세부 항목을 체크할 때마다 진행률이 반영됩니다. 모든 항목이 끝나면 묶음 할 일도 자동으로 완료됩니다.
